# Contributing to get-next-env

Thank you for considering contributing to `get-next-env`!

## Local Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/manishthomas/get-next-env.git
   cd get-next-env
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run tests and linting:
   ```bash
   npm test
   npm run lint
   npm run build
   ```

## Submitting Pull Requests

1. Create a feature branch off `main`.
2. Make your changes and add tests for any new features or bug fixes.
3. Run `npm run changeset` to create a changeset file describing your changes.
4. Push your branch and open a Pull Request.
